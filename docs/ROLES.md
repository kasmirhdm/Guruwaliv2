# GuruWali V2 Roles

## Admin GuruWali
Platform-wide access:
- schools
- school administrators
- users
- global curriculum/master data
- global templates
- platform settings
- activity/monitoring

## Admin Sekolah
School-scoped access:
- teachers
- students
- classes
- subjects
- academic years
- school curriculum activation
- school templates
- letterhead

## Guru
Teacher-scoped access:
- dashboard
- curriculum available to the teacher
- teaching devices
- documents
- assessments
- profile

Teacher account modes:
- INDIVIDUAL
- SCHOOL

## Wali Kelas
Not a separate authentication role. A teacher receives a homeroom assignment for a class and gets:
- students
- attendance
- grades
- notes
- achievements
- reports
